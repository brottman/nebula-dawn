# Taste

## UI layout

- Prefers game HUD controls (pause, bomb, weapon switcher) consolidated into a fixed bottom bar anchored to the screen edge, rather than floating buttons that overlay the playfield/action area. Confidence: 0.7
- Prefers discrete 5-segment health bar over continuous ProgressBar/energy bar (1 hit = 1 segment) — explicitly chose "5 bar" when offered 3 vs 5. Confidence: 0.9
